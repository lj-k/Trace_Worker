CPU 访存 Trace 流水线可视化

解析 Time;Tag;K:V;… 格式的仿真访存 trace，
以流水泳道呈现 LSU → L2C → 预取器 → 总线 的完整数据流，并可随仿真器写入实时跟进。

📡
打开并实时跟进 以只读方式跟进仿真器新写入的行。localhost / https 下全自动增量；直接双击打开本页面（file://）时，会每 4 秒提示你重新选择同一文件以追加新行，无需手动反复打开。
📂
载入文件（离线） 拖拽文件到窗口，或点击选择。一次性解析，适合仿真结束后的复盘分析。任何环境可用。
🎲
生成示例数据 没有 trace？生成一段模拟 openC910 + 预取器行为的数据，立刻体验全部功能。
要实时跟进？ 在 trace 所在目录执行 python3 serve.py，浏览器打开它给出的 http://localhost:8777/ 地址， 即可使用「打开并实时跟进」或「URL」两种实时模式。全程只读，绝不写回 trace 文件。

🌐 通过 URL 实时跟进

输入 trace 文件的 HTTP(S) 地址。前端使用 Range 请求只拉取新增字节，服务器需支持范围请求（serve.py 已支持）。

⚙ 字段语义配置 — 定义字段进制、位域与枚举，译码结果显示在详情面板

JSON 格式。radix=进制(16/10/2)，bits=one-hot 位名数组(索引即位号)，enum=值到含义的映射，desc=字段说明。 内置默认值基于本 trace 的统计推断，请按你的 RTL 实际编码修改。配置保存在浏览器本地。
